# Art Director

Русский · [English](README.en.md)

Art Director — скилл для Claude Code, который помогает вести визуальный проект от идеи до готового результата. Он разбирается в задаче, предлагает стиль и превращает его в понятные задания для Codex. После выполнения проверяет, как всё выглядит и работает, и формулирует конкретные правки.

Подходит для сайтов, интерфейсов приложений и работы с изображениями.

## Что умеет

- Изучать проект, его ограничения и визуальные референсы.
- Продумывать композицию, типографику, цвета, изображения и анимацию.
- Готовить небольшой эскиз для согласования направления.
- Составлять подробные задания для Codex с понятными критериями готовности.
- Распределять независимые задачи между агентами.
- Проверять результат: внешний вид, адаптивность, взаимодействия и доступность.
- Организовывать генерацию и сборку изображений, выбор вариантов и проверку деталей.
- Сохранять настройки проекта, доступные инструменты и ограничения для следующих этапов.
- Собирать исследования с источниками и проверять выводы перед подготовкой текстов.
- Готовить черновики обращений, материалы для встречи и план небольшого эксперимента по запросу.

Для выполнения задач через агентов нужен установленный и настроенный Codex CLI. Генераторы и редакторы изображений подключаются отдельно, если нужны для задачи.

В репозитории — инструкции, пустые шаблоны, служебные скрипты и тесты.

## Установка

Скачайте репозиторий и из папки `art-director` выполните:

```bash
python3 scripts/install.py --scope personal
```

Скилл появится в `~/.claude/skills/art-director`. Для установки только в один проект:

```bash
python3 scripts/install.py --scope project --project /path/to/project
```

Установщик сохраняет существующие файлы и отказывается перезаписывать уже установленный скилл. Шаблоны `CLAUDE.md` и `AGENTS.md` можно вручную объединить с инструкциями проекта.

## Использование

В Claude Code вызовите `/art-director` и опишите задачу. Режимы: `setup` — настроить проект, `brief` — разобраться в задаче, `plan` — подготовить задания, `execute` — запустить выполнение, `image` — работать с изображениями, `research-outreach` — провести исследование и подготовить черновики обращений, `review` — проверить результат.

Скрипт запуска агентов сначала показывает план. Для выполнения нужны явные флаги `--execute --approve-sharing-code`; автоматически публиковать или объединять изменения он не умеет. Подробности — в [инструкции по запуску](references/orchestration.md).

## Проверка пакета

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют локальный имитатор Codex и не обращаются к моделям.

Полные инструкции — в [SKILL.md](SKILL.md).
