# Sources and acknowledgments

Art Director combines visual direction, detailed task planning, isolated Codex execution and independent review. The original package credited these projects as conceptual sources:

- [Observerstudio/orchestrate-skill](https://github.com/Observerstudio/orchestrate-skill): specification, delegation, review and data-sharing boundaries.
- [obra/superpowers](https://github.com/obra/superpowers): explicit planning, isolated tasks and review before integration.
- [Anthropic Frontend Design](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md): purposeful composition, typography and visual hierarchy.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): design systems and structured visual and UX guidance.
- [AslanMazhidov/design-review-skill](https://github.com/AslanMazhidov/design-review-skill): browser-based review across screen sizes.
- [Impeccable](https://github.com/pbakaus/impeccable): preserving visual identity and directing focused refinements.
- [Humbleteam Design Review](https://github.com/humbleteam/design-review): evidence-based findings and concrete corrections.
- [Anti UI Slop community description](https://buildwithclaude.com/skill/anti-ui-slop): product-specific choices rather than generic presentation.

The package contains authored instructions, templates and Python helpers. It does not bundle the upstream skills, source code, images or asset libraries. Credits do not imply a runtime dependency.
