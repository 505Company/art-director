## Shared evidence schema — every dimension uses it
| Entity ID | Dimension ID | Run ID | Stable fact ID | Literal fact / original quote | Original source title | Sanitized URL or permitted path / locator | Publication / event / access dates | Evidence class | Inference / unproven parts | Owner guess / identity status | Follow-up |
|---|---|---|---|---|---|---|---|---|---|---|---|

- Evidence class: CONFIRMED primary source / SECONDARY attributed report / USER-SUPPLIED / INFERRED / NOTHING FOUND. Use UNKNOWN for absent dates or owners; an inference is not a confirmed fact.
- Stable fact IDs and serial deduplication follow `references/data-workbooks.md`; retain conflicting evidence and source locators/timestamps.
- Deliver explanations in the user's language; keep source titles/quotes in original. No invented news, need, identity or numbers.
- NOTHING FOUND: attempted searches, date and limits. N/A: why the dimension cannot run, permission/tool gap and owner.
- User-provided contacts override routing research; record the source of confirmation. Public identity matching remains HYPOTHESIS until confirmed by the user.
- Sanitize personal tracking/user parameters before opening links; user-only access goes back to the user, not a workaround.
